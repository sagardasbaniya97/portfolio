# Sagar Das Baniya — Portfolio

Plain HTML, CSS and JavaScript. No build step, works on Vercel, Netlify and GitHub Pages.

## Files
- `index.html` — page content (hero, about, skills, projects, certificates, contact)
- `css/style.css` — all styles
- `js/main.js` — loader, cursor, particles, typing effect, scroll effects, contact form
- `favicon.svg` — browser tab icon
- `vercel.json` — Vercel settings

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. Go to vercel.com/new and import the repository.
3. Leave all settings as they are and click Deploy.

## Edit content
Change text, project links or certificate links directly in `index.html`.
